# 🩸 Blood Donor Network

A web-based Blood Donor Management System built with Django that connects blood donors, recipients, hospitals, and administrators through a centralized platform. The system enables users to manage blood requests, donor registrations, notifications, and hospital records efficiently.

---

## 🚀 Features

### 👤 User Authentication
- Secure user registration and login
- Role-based access (Admin, Donor, Recipient, Hospital)
- Profile management

### 🩸 Donor Management
- Donor registration
- Blood group and availability management
- Search donors by blood group and location

### 🏥 Hospital Portal
- Hospital registration
- Manage blood requests
- View donor information

### 📢 Blood Requests
- Create emergency blood requests
- Track request status
- View request history

### 🔔 Notifications
- Notify users about blood requests
- Request status updates

### 📊 Dashboard & Reports
- Interactive dashboard
- Blood inventory statistics
- Donor and request reports

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/Khushi55aro/BloodDonor_Network.git
```

2. Navigate to the project

```bash
cd BloodDonor-Network
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Apply migrations

```bash
python manage.py migrate
```

5. Run the development server

```bash
python manage.py runserver
```
