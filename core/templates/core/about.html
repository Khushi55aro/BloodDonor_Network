About Blood Donor Network

Blood Donor Network with Geo-Matching is a beginner-friendly Django web application designed to connect recipients requiring urgent blood donations with eligible nearby donors.

Core Features
  • Role-Based Access Control: Donor, Recipient, Admin.
  • Automatic Donor Eligibility: Computes 90-day cooldown period from last donation date.
  • Blood Compatibility Matching: Built-in compatibility matrix for donor-recipient matching.
  • Geo-Matching Algorithm: Uses Haversine distance formula to match nearest donors within 30 km.
  • Emergency Request Broadcast: Notifies nearby eligible donors for emergency requests.
